# Threads @honjasseobom 자동 게시 (혼자써봄 · 생활필수품 뉴스)

생활필수품 뉴스 기사 한 건을 스레드(첫 글 + 답글 1개)로 바꿔 하루 2번(08:00, 20:00) Threads에 자동으로 올립니다. 말투는 편한 반말입니다.

- 재료: 컨슈머치·소비자경제·컨슈머타임스·식품음료신문 공식 RSS. 선별 AI가 채점해서 가장 쓸모 있는 기사를 고르고, 본문을 읽어 글을 씁니다.
- 안전장치: 기사 본문과 사실 대조(근거 없는 숫자·효과 차단), 과장·단정 표현 차단, 1인칭 경험담 차단, 민감 주제 제외.
- 구제 발행: 기사 3개를 두 번씩 다시 써도 검수에 떨어지면, 가장 나은 원고에서 문제 줄만 빼고 올립니다 (회차를 건너뛰지 않음, 텔레그램에 ⚠️ 표시).
- 출처: 답글 맨 아래에 매체명과 기사 링크를 코드가 붙입니다.
- 20:00: 인포크(link.inpock.co.kr/shoperwoody) 제휴 제품 추천 (첫 글 + 답글 2개, 광고 고지는 코드가 붙임). @damz0324와 겹치지 않게 목록 뒤에서부터 고르고, 다 올리면 뉴스 글로 바뀝니다.
- 텔레그램: 같은 봇, `[Threads 혼자써봄]`, 명령 `/hj_stop` `/hj_skip` `/hj_resume`
- 정시 실행: `~/Projects/인스타피드 건강뉴스 자동화/scheduler` (Cloudflare 정시 알람). GitHub cron은 예비.
