# Threads @honjasseobom 자동 게시 (혼자써봄 · 생활필수품 뉴스)

생활필수품 뉴스 기사 한 건을 스레드(첫 글 + 답글 1개)로 바꿔 하루 2번(08:00, 20:00) Threads에 자동으로 올립니다. 말투는 편한 반말입니다.

- 재료: 컨슈머치·소비자경제·컨슈머타임스·식품음료신문 공식 RSS. 선별 AI가 채점해서 가장 쓸모 있는 기사를 고르고, 본문을 읽어 글을 씁니다.
- 안전장치: 기사 본문과 사실 대조(근거 없는 숫자·효과 차단), 과장·단정 표현 차단, 1인칭 경험담 차단, 민감 주제 제외.
- 구제 발행: 기사 3개를 두 번씩 다시 써도 검수에 떨어지면, 가장 나은 원고에서 문제 줄만 빼고 올립니다 (회차를 건너뛰지 않음, 텔레그램에 ⚠️ 표시).
- 출처: 답글 맨 아래에 매체명과 기사 링크를 코드가 붙입니다.
- 20:00: 이틀에 한 번 인포크(link.inpock.co.kr/shoperwoody) 제휴 제품 추천 (첫 글 + 답글 2개, 광고 고지는 코드가 붙임). @damz0324와 겹치지 않게 목록 뒤에서부터 고르고, 다 올리면 뉴스 글로 바뀝니다.
- 2026-10-03 개편 (조회수 분석: 일 중앙값 274→23, 상위 글은 전부 "돈 함정" 소비자 기사, 제품 글 중앙값 24 vs 뉴스 114.5):
  - 선별: 위약금·해지/환불 거부·허위과장광고·할부/약정·숨은 수수료/자동결제·피해 주의보·가격 꼼수 기사를 최우선 채점 (`prompts/selector.md`), 제목·요약에 `channel.PRIORITY_WORDS`가 있으면 +1점 (5점 이상만, `src/selector.py`).
  - 제품 글은 이틀에 한 번: `channel.PRODUCT_DAY_PARITY`(날짜 서수 홀짝, 0이면 10/3·10/5…)인 날만 20:00 제품 글, 다른 날은 20:00도 뉴스. 제품 첫 글은 "헐… 이거 하나면" 틀 대신 그 제품 종류의 손해 함정으로 연다 (`prompts/product.md`).
  - 뉴스 답글에 리포스트를 부르는 자연스러운 한 줄 (필요한 사람 떠올리기, 조건 거래·애원 금지, 건강노트와 같은 방식). 교차 추천은 꺼 둠(`CROSS_PROMO = ''`).
  - 댓글 자동 답글: `--job reply` (`src/replies.py`, `prompts/reply.md`). 최근 3일 글의 새 댓글에 반말로 짧게 답함, 한 번 5개·하루 20개 한도, 정체 질문·스팸·민감 댓글은 건너뜀, 지어낸 경험·제품 권유·링크는 코드가 막음. 처리 기록은 `data/replied.json`. 정시 실행은 Cloudflare 알람에서 threads.yml을 `job=reply`로 호출.
- 텔레그램: 같은 봇, `[Threads 혼자써봄]`, 명령 `/hj_stop` `/hj_skip` `/hj_resume`
- 정시 실행: `~/Projects/인스타피드 건강뉴스 자동화/scheduler` (Cloudflare 정시 알람). GitHub cron은 예비.
- 채널별 차이는 `src/channel.py`와 `prompts/`뿐입니다. 다른 뉴스 채널(혼자써봄·건강노트)과 코드가 같으니 고칠 때 둘 다 확인하세요.
