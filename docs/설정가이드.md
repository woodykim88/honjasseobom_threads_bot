# Threads 연결 가이드 (@honjasseobom)

1. Meta 개발자 앱의 Threads 이용 사례에서 `honjasseobom` 토큰을 발급합니다 (권한: `threads_basic`, `threads_content_publish`).
2. `.env`의 `THREADS_ACCESS_TOKEN=` 뒤에 붙여 넣고 확인합니다 (사용자 ID 자동 기록).
   ```
   cd ~/Projects/"스레드  생활필수품 위주 뉴스 자동화 (채널명 : 혼자써봄)"
   "../구글블로그 AI뉴스 소식 자동화/.venv/bin/python" scripts/check_threads.py
   ```
3. GitHub 토큰(cardnews-secrets)의 Repository access에 이 저장소를 추가합니다 (또는 All repositories). 토큰 자동 갱신과 정시 알람이 이 권한을 씁니다.
4. 비밀값 등록
   ```
   "../구글블로그 AI뉴스 소식 자동화/.venv/bin/python" scripts/set_github_secrets.py
   ```
